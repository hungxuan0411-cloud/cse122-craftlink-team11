# CraftLink — CSE122

Sàn sản phẩm sáng tạo tùy biến (Frontend prototype) cho học phần **Phát triển ứng dụng Web cơ bản – CSE122**.

## Mục tiêu
CraftLink mô phỏng một marketplace/creator-commerce có nhiều vai trò, CRUD có ý nghĩa, responsive UI, JavaScript/DOM, dữ liệu mock và 3 trải nghiệm AI.

## Vai trò
- Khách hàng
- Người sáng tạo
- Kiểm duyệt viên
- Quản trị viên

## Quy trình Git
`main` ← phát hành ổn định
`dev`  ← tích hợp
`feature/*` ← phát triển tính năng
`fix/*` ← sửa lỗi
`docs/*` ← tài liệu

## Tài liệu
Xem thư mục `docs/` và `design/`.
