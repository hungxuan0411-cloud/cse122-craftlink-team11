# Roles & Features

| Role | Core responsibility | Primary features |
|---|---|---|
| Buyer | Tạo brief và theo dõi đơn | Marketplace, Custom Brief, Orders, Proposal/Revision |
| Maker | Quản lý sản phẩm và proposal | Listing Management, Brief Inbox, Proposal Editor |
| Moderator | Duyệt nội dung và xử lý báo cáo | Moderation Queue, Report Center, Content Guidelines |
| Admin | Quản trị taxonomy và tài khoản | Platform Dashboard, Category Management, User Management |

## Shared screens under consideration
- Landing / Marketplace
- Login
- Register
- Profile
- Notifications
- 403 / 404 / Forgot Password / Settings khi nghiệp vụ yêu cầu
